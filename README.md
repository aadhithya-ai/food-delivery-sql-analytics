# 🍔 Food Delivery Order & Customer Analytics System

## 📌 Project Overview

This project is a **Food Delivery Order & Customer Analytics System** built using **MySQL**.

The objective is to design a relational database for a food delivery platform and use SQL queries to generate meaningful business insights from customer, restaurant, order, payment, and delivery data.

## 🗄️ Database Structure

The database contains **8 relational tables**:

* Customers
* Restaurants
* Menu Items
* Orders
* Order Items
* Delivery Partners
* Deliveries
* Payments

## 🔍 Key Analysis Performed

The project analyzes:

* Customer order history and spending
* Repeat customers
* Restaurant-wise orders and revenue
* Top-selling food items
* Food item revenue
* Payment method usage
* Successful and failed payments
* Delivery partner performance
* Average delivery time
* Monthly revenue
* City-wise revenue
* Order cancellation analysis
* Customer spending rankings
* Restaurant-wise food rankings
